## 流量套餐的"双向计费"要算清楚

流量计费套餐的额度是上下行双向合计的，实际可用量比表面数字少，这点很多介绍文章都没写明白。

第三方在 2023 年底实测过的 500GB 档套餐，页面明确标注“500GB（双向流量）"，带宽 150Mbps。也就是说上传的每 1GB 和下载的每 1GB 都从额度里扣。做数据同步、备份这类上下行都大的业务，按表面数字的一半来规划用量才稳妥。流量需求大的话，独享带宽计费没有这个扣减问题，但价格结构不同，需要按业务量自己算一笔账。

## 下单前必须确认的五件事

实名、省份、付款、退款、地域限制，这五条都写在官网 FAQ 和服务条款里，逐条对一遍能省掉大部分售后麻烦。

1. **实名认证**：IPLC/IEPL 产品需要用国内手机号（身份信息）完成实名，这是使用前提，绕不开。
2. **省级白名单**：有白名单限制的产品只能在选定的省份使用，同一时间只允许一个省份的 IP 接入。部署时要先选好省份，之后官网写明省份可随时切换，但多省同时使用不行。需要频繁更换接入地区或全国多点并行的用户，这套机制会很别扭。
3. **付款方式**：目前只支持支付宝，官方表示更多支付方式后续会加。
4. **退款政策**：只支持质量问题退款，且需要证据——准确的延迟数据、速度数据，用来证明确实是产品质量问题。
5. **地域锁定**：服务开通后不支持更换到其他地域的产品，选线路时别抱着“先买后换”的想法。

> 官网 FAQ 原文：“仅支持质量问题退款，服务开通后不支持更换到其他地域的产品。”

第 4、5 条合起来意味着：下单前把线路方向和接入省份一次定对，比事后补救划算得多。

## 常见问题

**MKCloud 需要实名认证吗？**

需要。IPLC/IEPL 专线产品要求国内手机号实名认证，这也是这类产品的合规基础。

**可以退款吗？**

只有质量问题可以退，而且要拿出具体的延迟、速度测试数据作为证据。没有无理由退款，开通后也不能换成其他地域的产品。

**能同时在多个省份使用吗？**

不能。白名单机制下一次只允许一个省份接入，省份可以切换，但任意时刻只有一个省生效。多省并行需要买多台，或者考虑别的方案。

**有 IPv6 吗？**

2023 年底的实测中，沪日 IPLC 套餐没有 IPv6，广港 IEPL 套餐有原生 IPv6。当前各线路的分配情况建议下单前向客服确认。

**哪些人不适合 MKCloud？**

两类人：需要频繁更换接入省份或多省同时接入的；以及只想找便宜共享 VPS 的。它的价格和产品形态都是按专线用户设计的，用不上专线能力就没必要花这个钱。
